# CodeAlpha_Matrix_Operations

## Overview
A C program designed to perform foundational matrix operations. Developed for the CodeAlpha C Programming Internship, this project demonstrates the use of 2D arrays and modular programming through discrete functions.

## Features
* **Matrix Addition:** Adds two matrices of the same dimensions.
* **Matrix Multiplication:** Multiplies two matrices using nested iteration.
* **Matrix Transposition:** Flips a matrix over its diagonal.

## How to Run
1. Compile the program: `gcc matrix_ops.c -o matrix_ops`
2. Execute the compiled file: `./matrix_ops`
3. Input the matrix elements when prompted in the terminal.
