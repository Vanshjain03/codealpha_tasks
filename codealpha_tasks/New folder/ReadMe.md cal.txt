# CodeAlpha_Calculator

## Overview
A basic arithmetic calculator developed in C as part of the CodeAlpha C Programming Internship. The program utilizes a `switch-case` structure to perform fundamental mathematical operations based on user input.

## Features
* **Addition (+)**
* **Subtraction (-)**
* **Multiplication (*)**
* **Division (/)** with built-in zero-division validation

## How to Run
1. Compile the program: `gcc calculator.c -o calculator`
2. Execute the compiled file: `./calculator`
3. Follow the on-screen prompts to select an operator and enter two operands.
