# CodeAlpha C Programming Internship Tasks

## Overview

This repository contains the C programming projects completed during the **CodeAlpha Internship**. The tasks demonstrate a strong foundation in C programming, including control structures, arrays, functions, structures, and file handling.

## Projects Included

### 1. Basic Calculator Program (Task 1)

A command-line calculator that performs fundamental arithmetic operations.

* **Features:** Addition, Subtraction, Multiplication, and Division.

* **Concepts Used:** `switch-case` statements, basic I/O, and error handling (division by zero).

* **How to run:**

  ```
  gcc calculator.c -o calculator
  ./calculator
  
  ```

### 2. Matrix Operations (Task 2)

A program designed to perform foundational matrix mathematics.

* **Features:** Matrix Addition, Matrix Multiplication, and Matrix Transposition.

* **Concepts Used:** 2D Arrays, nested loops, and modular programming with functions.

* **How to run:**

  ```
  gcc matrix_ops.c -o matrix_ops
  ./matrix_ops
  
  ```

### 3. Banking System (Task 4 - Mini Project)

A Bank Account Management System that persistently stores user data.

* **Features:** Deposit funds, Withdraw funds, and Balance Enquiry.

* **Concepts Used:** `structs`, binary file handling (`fwrite`, `fread`), and menu-driven execution.

* **How to run:**

  ```
  gcc banking_system.c -o banking_system
  ./banking_system
  
  ```

*(Note: The banking system automatically generates a `bank_data.dat` file on the first run to store account details.)*
